# Clip to Markdown 隐私政策

最后更新：2026 年 9 月 4 日

Clip to Markdown 是一款用于网页阅读、内容整理和 Markdown 剪藏的浏览器扩展。

本隐私政策说明 Clip to Markdown 在使用 Markdown 保存、AI 速览、B站字幕阅读和 Obsidian 等功能时，会处理哪些数据，以及这些数据如何被使用和保存。

## 一、处理的数据

### 1. 网页内容

当用户主动使用 Clip to Markdown 的相关功能时，扩展会读取当前受支持页面中的必要内容，例如：

- 标题
- 作者
- 发布时间
- 正文文本
- 图片和图片链接
- 超链接
- 引用、代码块和表格
- 当前页面网址
- 视频标题、简介、章节和可用字幕

目前支持的主要平台包括：

- X / Twitter
- 知乎
- Bilibili
- ChatGPT
- 小黑盒

这些内容仅用于用户主动请求的阅读、整理、AI 速览或保存操作。

Clip to Markdown 不会在后台持续记录用户访问的网站，也不会建立用户浏览历史。

### 2. ChatGPT 对话内容

当用户在 ChatGPT 页面使用 Markdown 保存或 AI 速览功能时，扩展会处理当前页面中用户和助手可见的对话内容。

这些内容仅用于用户主动请求的导出、整理或 AI 速览，不用于分析用户的聊天行为或建立用户画像。

### 3. AI 服务配置

如果用户启用 AI 功能，扩展会在浏览器本地保存：

- AI API Endpoint
- API Key
- 模型名称
- AI 功能相关设置

这些配置保存在浏览器本地存储中。

AI API Key 仅由扩展后台读取，不会写入网页，也不会发送给 Clip to Markdown 开发者服务器。

### 4. Obsidian 配置

如果用户启用 Obsidian 功能，扩展会在浏览器本地保存：

- Obsidian Local REST API 地址
- API Key
- Vault 内的笔记目录
- 其他与 Obsidian 保存相关的设置

这些信息仅用于与用户自己电脑上运行的 Obsidian Local REST API 通信。

### 5. 保存设置

扩展可能在浏览器本地保存用户设置，例如：

- Markdown 保存目录
- 下载设置
- 文件命名规则
- Frontmatter 选项
- 快捷键相关配置
- AI 和字幕相关设置

如果用户选择自定义本地文件夹，浏览器可能保存该文件夹的访问授权信息，以便后续继续向用户选择的目录写入文件。

## 二、AI 速览

当用户主动触发 AI 速览时，Clip to Markdown 会提取当前受支持页面中的必要文本，并发送到用户配置的 AI 服务，用于生成：

- 两句话摘要
- 核心观点
- 内容结构
- 原文定位所需的信息

AI 速览不会在用户未主动触发时自动发送网页内容。

对于支持原文定位的页面，扩展可能为正文生成内部内容块标识，并向 AI 服务提供必要的文本信息，以便将生成的内容结构与原文对应。

AI 返回的速览结果及相关临时状态可能保存在浏览器会话存储中，用于在当前浏览器会话中展示结果和维持侧栏状态。

这些 AI 速览结果不会自动写入网页，也不会因为普通 Markdown 保存而自动加入导出的正文。

## 三、Bilibili 字幕阅读

当用户使用 B站字幕阅读功能时，扩展会访问 Bilibili 提供的视频信息和字幕资源，以获取：

- 视频基本信息
- 章节信息
- 可用字幕轨
- 字幕文本和对应时间点

字幕阅读功能用于：

- 展示字幕
- 切换字幕轨
- 播放时跟随当前字幕
- 点击字幕跳转到对应视频时间点

Clip to Markdown 不会为了字幕阅读而下载视频或音频，也不会进行本地或云端语音识别（ASR），不会对视频画面进行 OCR。

## 四、Bilibili AI 字幕翻译

只有在满足相关条件，并且用户主动启用字幕翻译功能时，扩展才会调用用户配置的 AI 服务进行字幕翻译。

进行 AI 字幕翻译时，只发送需要翻译的字幕文本。

不会发送：

- 视频文件
- 音频文件
- 视频画面
- BV 号
- 视频标题
- 视频作者

AI 字幕翻译产生的 API 请求可能由用户所选择的 AI 服务商收费。

## 五、数据用途

Clip to Markdown 处理上述数据，仅用于用户主动请求的核心功能，包括：

- 网页内容读取与整理
- Markdown 生成和导出
- 本地文件保存
- Obsidian 笔记保存
- AI 速览
- 原文定位
- Bilibili 字幕阅读
- Bilibili 字幕 AI 翻译

Clip to Markdown 不会将这些数据用于：

- 广告投放
- 用户跟踪
- 跨网站跟踪
- 用户画像
- 浏览历史分析
- 信用评估
- 贷款或金融决策
- 与扩展核心功能无关的数据分析

## 六、数据保存

### 浏览器本地

扩展设置、AI 配置和 Obsidian 配置主要保存在用户浏览器本地。

### 浏览器会话

AI 速览结果、页面定位状态以及部分字幕相关临时数据可能保存在浏览器会话存储中，用于维持当前会话中的功能状态。

这些数据不作为长期用户行为记录使用。

### Markdown 文件

用户选择保存 Markdown 后，文件会保存到：

- 用户选择的自定义本地文件夹；或
- 浏览器下载目录及其子目录。

### Obsidian

使用 Obsidian 功能时，生成的 Markdown 会通过用户自己配置的 Local REST API 写入用户自己的 Obsidian Vault。

## 七、数据传输

Clip to Markdown 不运营用于接收或保存用户网页剪藏内容的服务器。

普通 Markdown 保存主要在用户设备本地完成。

Obsidian 保存仅与用户本机配置的 Obsidian Local REST API 通信。

只有在用户主动使用 AI 速览或 AI 字幕翻译等 AI 功能时，相关文本才会发送到用户配置的 AI API 服务。

这些请求直接发送到用户选择的 AI 服务商，不经过 Clip to Markdown 开发者服务器。

第三方 AI 服务对相关数据的处理可能受其自身隐私政策和服务条款约束，用户应根据自己选择的 AI 服务了解相关政策。

## 八、API Key 和身份验证信息

Clip to Markdown 可能处理以下由用户自行提供的身份验证信息：

- AI API Key
- Obsidian Local REST API Key

这些信息仅用于完成用户配置的对应功能。

开发者不会主动收集这些 API Key，也不会将其发送到 Clip to Markdown 开发者服务器。

用户应妥善保护自己的 API Key，并在认为凭证可能泄露时及时前往对应服务商进行撤销或更换。

## 九、数据出售与共享

Clip to Markdown 不出售用户数据。

不会为了广告、营销、用户画像、信用评估或其他与扩展核心功能无关的目的，将用户数据出售或传输给第三方。

当用户主动使用 AI 功能时，将必要文本发送给用户自行配置的 AI 服务商，仅用于完成用户所请求的 AI 功能。

## 十、用户控制

用户可以随时：

- 删除已经导出的 Markdown 文件
- 删除 Obsidian 中保存的笔记
- 关闭 AI 功能
- 关闭 B站 AI 字幕翻译
- 修改或清除 AI API 配置
- 修改或清除 Obsidian 配置
- 更换或撤销相关 API Key
- 清除扩展设置
- 卸载 Clip to Markdown

卸载扩展后，由扩展保存在浏览器中的本地数据会按照浏览器自身的扩展数据管理机制进行处理。

已经保存到用户本地文件夹、下载目录或 Obsidian Vault 的文件不会因为卸载扩展而自动删除。

## 十一、权限说明

Clip to Markdown 仅申请实现核心功能所需的浏览器权限。

这些权限用于：

- 读取用户当前主动操作的受支持网页
- 保存 Markdown 文件
- 保存扩展设置
- 显示操作结果通知
- 展示 AI 速览和字幕阅读侧栏
- 向用户选择的自定义目录写入 Markdown
- 与用户本机的 Obsidian 服务通信
- 在用户主动配置后访问其选择的 AI API Endpoint

这些权限不会用于广告、用户跟踪或浏览行为监控。

## 十二、隐私政策更新

随着 Clip to Markdown 功能发生变化，本隐私政策可能会进行更新。

如果涉及数据处理方式的重要变化，将在本页面更新相关说明。

建议用户定期查看本隐私政策了解最新内容。
