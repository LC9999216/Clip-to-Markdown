# 👁️ GlanceClip

**先看懂，再收藏。** GlanceClip 是一个 AI 浏览器阅读与剪藏助手：在 **X、知乎、Bilibili、ChatGPT、小黑盒** 的内容页里，先用「一图速览」读出两句话摘要、核心观点和内容结构，确认有价值后，再把干净的 Markdown 收进本地文件夹或 Obsidian。

> 只提取“内容本体”：标题、作者、发布时间、正文、图片、链接、引用和原文地址；尽量排除评论、回复、推荐、广告、侧边栏和操作按钮。

> 🏷️ **品牌说明**：项目展示名已更新为 GlanceClip；浏览器扩展内部仍显示 **Clip to Markdown**（manifest、页面标题与已保存文件保持原名），功能不受影响。

## 📦 安装

目前通过源码安装，需要 **Chrome 116+** 与 **Node.js**。

### 1. 获取并构建

```bash
git clone https://github.com/LC9999216/clip2md.git
cd clip2md
npm ci
npm run build
```

如果 `npm ci` 因锁文件问题失败，再退回：

```bash
npm install
npm run build
```

### 2. 加载到 Chrome

1. 打开 `chrome://extensions`
2. 开启 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择项目里的 `dist` 文件夹
5. 将扩展固定到工具栏

完成 🎉

## 🚀 快速开始

打开支持平台的具体内容详情页，然后：

- **保存为 Markdown** → 保存到浏览器下载目录或自定义文件夹
- **保存到 Obsidian** → 直接进入 Obsidian 知识库
- **打开一图速览** → 侧栏生成摘要、观点与结构，先读后藏

### 快捷键

| 功能 | 默认快捷键 |
| --- | --- |
| 保存为 Markdown | `Ctrl + Shift + S` |
| 保存到 Obsidian | `Alt + Shift + S` |
| 打开一图速览 | `Ctrl + Shift + Y` |

Mac：保存为 Markdown `Command + Shift + S`，一图速览 `Command + Shift + Y`。

快捷键冲突时，前往 `chrome://extensions/shortcuts` 重新绑定。

## 🧭 功能介绍

### 不只是 Web Clipper

传统剪藏工具只做一件事：把网页搬进笔记库。GlanceClip 的使用逻辑是**先摘要、再定位、最后收藏**：

1. **先摘要**：在内容页打开侧栏触发「一图速览」，先看两句话摘要和核心观点，判断这篇文章值不值得读、值不值得存；
2. **再定位**：通过内容结构跳回原文对应位置精读，B站视频还能直接跳到字幕对应时间点；
3. **最后收藏**：确认有价值，再用原有的保存链路把干净 Markdown 收进本地或 Obsidian。

无论读没读完，收藏下来的永远只是“内容本体”：标题、作者、发布时间、正文、图片、链接、引用和原文地址；评论、回复、推荐、广告、侧边栏和操作按钮都会被尽量排除。

### 一图速览

在受支持平台的具体内容页按 `Ctrl + Shift + Y`，即可打开 Side Panel 并生成：

- **两句话摘要**：这篇内容在讲什么；
- **核心观点**：作者的关键论点列表；
- **内容结构**：章节化的要点目录；
- **可靠原文定位**：点击结构条目滚动回原文并高亮，B站条目定位到字幕或章节时间点。

![一图速览演示：在公开文章页触发分析，生成两句话摘要、核心观点与内容结构，点击结构条目定位并高亮原文](docs/assets/readme/visual-summary-demo.gif)

能力边界：

- **只在主动触发时发送正文**：只有按下快捷键或点击「重新生成」才把当前页面正文发送到你配置的 AI 服务，不会自动分析网页；
- **来源定位要求可靠**：知乎、小黑盒、ChatGPT 和 X Article 的结构条目会重新核对页面、来源块编号和短引用，只有唯一匹配时才滚动并高亮；**X 的可靠原文定位仅限 X Article**，普通推文没有可靠锚点时，内容结构保持静态展示，不伪装可跳转；
- **失败自动恢复**：AI 返回的原文短引用只有轻微标点或空格差异时，先在本地 Source Block 中保守重匹配；输出仍不合规时自动 repair，并最多再完整生成一次。正常成功只请求一次，本地恢复成功不增加 AI 请求；输出不合规时单次主动生成最多可能触发 3 次 AI 请求及相应费用；
- **结果可缓存**：同一页面同一模型的结果会临时缓存，避免重复消耗额度；点击「重新生成」可强制刷新；
- **看完再收藏**：Side Panel 里确认内容有价值后，点击「保存 Markdown」即可复用原有保存链路。

> 一图速览只在当前页面主动触发时读取内容，并发送给用户配置的 AI 服务。失败自动恢复的三个阶段（初次生成、一次修复、一次全新生成）都属于同一次用户主动操作，扩展不会在后台自动发送正文。Bilibili 无字幕时仍可保存标题、简介和章节，并在分析中明确标注暂无字幕。

### B站字幕阅读

在 B站视频或分 P 页面打开侧栏时，右上角会出现「字幕」入口（仅 B站视频页显示，与一图速览是否生成无关）。点击进入 **B站独立字幕页**，像读文章一样读视频：

![B站字幕阅读演示：打开独立字幕页，切换字幕轨，播放时当前句自动跟随高亮，点击字幕行跳转视频时间点](docs/assets/readme/bilibili-subtitle-demo.gif)

功能范围：

- **官方字幕优先**：只读取 B站官方人工或 AI 字幕轨（`x/player/wbi/v2` 与字幕 CDN），按「人工中文 → AI 中文 → 其他人工 → 其他 AI」自动选择；视频没有字幕轨时明确提示。不下载视频，不做语音识别或画面 OCR；
- **简体中文（AI 翻译）**：仅当视频没有官方简体中文轨、但存在英文字幕轨，且你在设置中显式开启「B站无简中轨时自动翻译」时，字幕页才会默认显示“简体中文（AI 翻译）”虚拟轨；只把英文字幕文本发送到你配置的 AI 服务，**不会发送音频或视频**，也不发送 BV 号、标题、作者等页面信息；调用**可能产生费用**，翻译结果只缓存在当前浏览器会话；
- **轨道切换**：可手动切回官方 English / 日本語 等原始轨道；手动选择在当前浏览器会话内记忆，自动选择不覆盖手动偏好；
- **时间跳转**：点击字幕行跳转播放器到对应时间，保持原本的播放/暂停状态不变；
- **当前句高亮与自动跟随**：页面可见时每 0.5 秒跟随播放位置；手动滚动后暂停跟随，点击「回到当前句」立即回到当前句并恢复跟随；
- **会话缓存**：同一视频、同一分 P、同一轨道的首次加载结果在当前浏览器会话内复用；点击刷新强制重新获取官方字幕并重新翻译；
- **细粒度展示分段**：字幕侧栏会在单条平台字幕内部按句读拆成约 4 秒的小段，方便阅读、点击跳转和随播放高亮；不会跨平台字幕行合并。平台未提供逐字时间码时，子段时间按文字位置在原字幕行内估算，这不是语音识别或逐字对齐；
- **无ASR**：不做本地或云端语音识别，不做画面 OCR；翻译失败时保留可读的官方字幕并给出精确提示。

字幕页不提供搜索、段数统计、复制、导出、双语对照、顺句或 ASR；需要登录 B站才能查看字幕轨的视频会明确提示登录。

> 参考来源：字幕获取、WBI 签名、轨道优先级与中文分段思路参考了 [biuworks/bilibili-digest](https://github.com/biuworks/bilibili-digest)（MIT），本项目按自身架构独立实现，未复制其代码；第三方许可详见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

### 一键收藏

读完决定收藏时，两种去向，一套快捷键：

- **保存为 Markdown**（`Ctrl + Shift + S`）：保存到浏览器下载目录，或在设置中指定本地文件夹直接写入；
- **保存到 Obsidian**（`Alt + Shift + S`）：通过本机 Local REST API 直接写入 Vault，无需中转文件。

收藏质量保障：

- **Markdown 语义保留**：标题、列表、链接、引用、代码块、表格、图片等内容会尽可能转换并保留为对应的 Markdown 结构；
- **全局文件命名规则**：普通下载、自定义文件夹、Obsidian 共用一套模板，详见[文件命名](#-文件命名)；
- **自定义保存目录**：Markdown 可直接写入指定文件夹，支持子目录。

### 平台能力总览

| 平台 | Markdown | 一图速览 | 原文定位 | 字幕阅读 |
| --- | --- | --- | --- | --- |
| X | ✅ 普通推文、X Article | ✅ | 仅 X Article 可靠定位；普通推文保持静态 | — |
| 知乎 | ✅ 回答、文章 | ✅ | ✅ 结构条目唯一匹配时滚动高亮 | — |
| Bilibili | ✅ 视频信息、简介、章节、字幕 | ✅ | ✅ 字幕/章节时间点 | ✅ 官方字幕轨 |
| ChatGPT | ✅ 用户与助手对话 | ✅ | ✅ 结构条目唯一匹配时滚动高亮 | — |
| 小黑盒 | ✅ 帖子、图文帖子 | ✅ | ✅ 结构条目唯一匹配时滚动高亮 | — |

网页提取主要在浏览器本地完成。B站字幕会读取 B站官方页面接口和字幕资源；Obsidian 模式连接本机 Local REST API。项目不自建内容服务器。

## ⚙️ AI 配置（一图速览，可选）

一图速览需要先配置一个 OpenAI-Compatible 的 AI 服务：

1. 打开 Clip to Markdown 设置页
2. 在「AI」区域填写：
   - **Endpoint**：如 `https://api.deepseek.com/chat/completions`（仅允许 HTTPS；本机调试可用 `http://127.0.0.1` / `http://localhost`）
   - **API Key**：你的服务商密钥（仅保存在浏览器本地，由扩展后台读取）
   - **Model**：如 `deepseek-chat`
3. 点击「授权并测试」：首次使用会请求该 API 域名的访问权限，测试成功后即可使用

## 🟣 保存到 Obsidian（可选）

如果希望直接保存到 Obsidian：

1. 在目标 Vault 中安装并启用 **Local REST API with MCP**
2. 开启 **Enable Non-encrypted (HTTP) Server**
3. 复制 API Key
4. 打开 Clip to Markdown 设置页
5. 填写 API 地址：

```text
http://127.0.0.1:27123
```

6. 填写 Vault 内笔记目录，例如：

```text
Clippings/Inbox
```

7. 点击 **测试连接**

连接成功后，即可使用 `Alt + Shift + S` 一键保存到 Obsidian。

> 笔记目录使用 Vault 内相对路径，不要填写 `C:\...` 这类电脑绝对路径。

## 📝 文件命名

默认模板：

```text
{date}-{title}
```

支持变量：

| 变量 | 含义 |
| --- | --- |
| `{title}` | 标题 |
| `{date}` | 剪藏日期 |
| `{author}` | 作者 |
| `{platform}` | 平台 |
| `{id}` | 内容 ID |

例如模板 `{date}-{platform}-{title}` 可生成：

```text
2026-08-17-知乎-如何使用DeepSeek.md
```

非法字符会自动清理，并统一补齐 `.md`。

## 📌 使用提示

- **X**：打开具体 `/status/{id}` 页面；可靠原文定位仅限 X Article
- **ChatGPT**：打开已有消息的 `/c/...` 对话页
- **Bilibili**：打开 `/video/BV...` 视频详情页；只保存视频信息与可用字幕，不下载视频。字幕功能请使用侧栏右上角的「字幕」入口进入独立字幕页
- **知乎**：推荐具体 `/answer/...` 回答页或 `zhuanlan.zhihu.com/p/...` 文章页
- **小黑盒**：打开 `/app/bbs/link/...` 帖子详情页

保存前请确认正文、图片、字幕或对话消息已经加载完成。

## ❓ 常见问题

### 显示“不支持当前页面”

确认打开的是具体内容详情页，刷新页面并等待正文加载完成后重试。

### 保存后找不到文件

检查设置页中的自定义文件夹、Chrome 默认下载目录、下载子目录或 Obsidian Vault。

### Obsidian 连接失败

确认 Obsidian 正在运行、Local REST API 已启用、HTTP Server 已开启、API 地址和 API Key 正确。

## ⚠️ 已知限制

- 需要登录的内容，只能保存当前账号实际可见部分
- 图片默认保留远程 URL，不会批量下载到本地
- X 视频不会完整下载
- 知乎折叠长回答只保存已展开部分
- B站没有可用字幕时不会自动语音识别；一图速览改用标题、简介和章节等可用元数据
- B站独立字幕页以官方字幕为准（无ASR、无OCR），不做双语对照与顺句；字幕轨需要登录的视频会提示先登录，播放器未加载时点击字幕行只提示稍后重试
- 字幕翻译兜底默认关闭：只有你显式开启且视频无官方中文轨、存在英文轨时才把英文字幕文本发送到你配置的 AI 服务；不会发送音频或视频，调用可能产生费用，翻译结果只在当前浏览器会话内缓存
- ChatGPT 的文件附件、图片附件、Canvas、语音和 Thinking 内部过程暂不作为独立内容保存
- Obsidian 模式需要本机运行 Local REST API
- 使用一图速览前需配置 OpenAI-Compatible AI 服务；B站时间定位依赖当前页面播放器仍然可用
