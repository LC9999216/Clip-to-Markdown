# Clip2MD B站独立字幕侧栏设计

**日期**：2026-08-29

**状态**：用户已批准

## 目标

在现有一图速览侧边栏之外，为 B 站视频增加一个完全独立的字幕 HTML 页面。扩展仍默认打开一图速览；用户只有点击原侧栏右上角的“字幕”按钮后才进入字幕页。字幕页读取 B 站官方人工或 AI 字幕，支持字幕轨切换、时间戳跳转、当前句高亮、自动跟随和“回到当前句”。

该功能仅适用于 B 站视频和分 P，不改变知乎、小黑盒、ChatGPT、X 等平台的侧边栏行为。

## 范围

首版包含：

- 两个独立页面：现有 `sidepanel.html` 与新增 `subtitle.html`。
- 原侧栏右上角、设置按钮左侧的“字幕”入口。
- 字幕页顶部的“返回一图速览”、刷新和设置入口。
- B 站官方字幕轨获取、自动选择和手动切换。
- 中文友好的字幕分段与时间戳展示。
- 点击字幕跳转播放器，保持原播放或暂停状态。
- 当前字幕高亮、自动滚动、手动滚动暂停跟随和“回到当前句”。
- 会话级字幕缓存、字幕轨选择和滚动位置恢复。

首版明确不包含：

- 字幕搜索、筛选或关键词高亮。
- 字幕段数统计、复制或导出。
- AI 翻译、双语对照、顺句或文本修正。
- 音频下载、本地语音识别或其他无字幕兜底。
- 概览、笔记、问答等参考项目的其他页面。

## 页面架构

扩展继续将 `sidepanel.html` 配置为默认 Side Panel 页面。现有 `sidepanel.ts` 和 `sidepanel.css` 继续只负责一图速览，不承载字幕列表或播放同步逻辑。

新增以下独立资源：

- `subtitle.html`：字幕页静态结构。
- `subtitle.ts`：字幕加载、状态管理、字幕轨切换、播放同步和页面导航。
- `subtitle.css`：字幕页专属样式。

构建脚本为 `subtitle.ts` 增加单独入口，并复制 `subtitle.html`、`subtitle.css` 到 `dist`。两个页面不得导入对方的页面控制器；可共享纯数据模块、消息类型、B 站身份解析和字幕服务。

### 一图速览入口

原侧栏的品牌栏保持左侧 `Clip to Markdown` 标识，右侧依次显示“字幕”和“设置”。“字幕”按钮仅在活动标签页 URL 是有效 B 站视频或分 P 时显示。显示条件直接来自活动标签页识别，不依赖一图速览是否已生成成功，因此生成中、未生成或生成失败时仍可进入字幕页。

点击“字幕”后，在当前 Side Panel 容器中导航到 `subtitle.html`。字幕页点击“返回一图速览”后导航回 `sidepanel.html`。页面切换允许重新加载文档；需要保留的状态通过 `chrome.storage.session` 恢复，而不是让两个页面共享 DOM 或运行时对象。

### 字幕页布局

字幕页从上到下依次为：

1. 顶部栏：“返回一图速览”、刷新、设置。
2. 当前视频标题。
3. 字幕轨下拉菜单。
4. 可滚动的时间戳与字幕正文列表。
5. 用户手动滚动后出现的“回到当前句”按钮。

页面不显示搜索框、字幕总段数、复制或导出按钮。所有视频标题、轨道名称和字幕正文均使用 `textContent` 渲染，不将接口文本作为 HTML 注入。

## 字幕数据流

字幕页第一次打开时才开始加载，不在一图速览页面预取：

1. 查询活动标签页并识别 BVID、分 P 和当前页面 URL。
2. 调用 B 站视频信息接口取得 aid、cid、标题和分 P 信息。
3. 获取 WBI 密钥并生成签名参数。
4. 使用浏览器当前 B 站登录态请求签名后的 `x/player/wbi/v2` 字幕轨列表。
5. 规范化人工/AI标记、语言代码、轨道名称和字幕 URL。
6. 按优先级自动选择轨道：人工中文字幕、AI 中文字幕、其他人工字幕、其他 AI 字幕。
7. 从字幕 CDN 下载选中轨道的 JSON。字幕 CDN 请求不附带无关 Cookie。
8. 将原始字幕转换为带稳定起止时间的显示段落并渲染。

用户切换字幕轨时复用已有视频信息，加载相应轨道并重新渲染。用户点击刷新时绕过当前视频字幕缓存，重新获取视频信息、WBI 密钥、字幕轨和选中轨道内容。

网络请求继续经过 background 的 B 站 JSON 代理和现有域名白名单，不增加非 B 站主机权限。WBI 签名、字幕解析和轨道选择放在独立、可单测的 B 站字幕模块中，避免继续扩大现有视频 Markdown 拼装函数。

## 字幕分段

字幕显示不采用现有一图速览的固定 60 秒窗口。分段算法保留原始时间轴，并优先在中文句号、问号、感叹号、逗号及原始字幕行边界处断句。

建议采用确定性阈值：中文段落理想约 90 字，最多 160 字或 20 秒；拉丁文字理想约 180 字符，最多 320 字符或 20 秒。达到上限但没有自然标点时，优先使用最近的原字幕行边界，最后才硬切。空白字幕被忽略，相邻内容不得因分段而丢字、重字或改变时间顺序。

## 缓存与页面状态

字幕缓存使用 `chrome.storage.session`，键至少包含 BVID、分 P/cid 和字幕轨标识。缓存值包含规范化轨道列表、选中轨道的原始或分段字幕、保存时间和视频身份。缓存仅在当前浏览器会话内有效，不写入长期用户数据。

页面状态按视频身份保存：

- 最近选择的字幕轨。
- 字幕列表的大致滚动位置。
- 已加载字幕缓存键。

搜索状态不存在，也不需要保存。活动标签页切换到其他视频或分 P 时，旧请求通过请求代次标识作废；旧响应不得覆盖新页面。返回同一视频时优先恢复会话缓存，点击刷新则强制重新请求。

## 播放器联动

字幕页通过面向 B 站内容脚本的明确消息读取和控制播放器：

- `GET_BILIBILI_PLAYBACK_STATE` 返回当前视频身份、`currentTime`、`paused` 和播放器是否可用。
- 字幕页仅在可见时按固定短间隔读取播放状态，并以当前时间定位字幕；实现应避免重排整个列表。
- `SEEK_BILIBILI_VIDEO` 携带预期 BVID/分 P 和目标秒数。内容脚本在身份一致时设置 `video.currentTime`。
- 跳转前记录播放器暂停状态；原来暂停则继续暂停，原来播放则继续播放，不因字幕点击自动开播。

当前时间命中某段字幕时，只更新上一段与当前段的高亮状态。自动跟随仅在用户未主动浏览字幕时生效。用户滚轮、触摸或拖动滚动条后暂停自动跟随并显示“回到当前句”；点击该按钮后立即滚到当前字幕并恢复跟随。

如果播放器未加载，字幕仍可阅读；读取状态返回不可用，点击时间戳时给出轻量提示，不循环触发播放或刷新页面。

## 错误状态

字幕页使用明确、互斥的状态，避免统一显示“生成失败”：

- 非 B 站视频页：`字幕功能仅支持B站视频页`。
- 需要登录：`请登录B站后刷新字幕`。
- 官方接口返回无字幕轨：`该视频暂无可用字幕`。
- 字幕轨存在但内容为空：`该字幕轨暂无内容`。
- WBI、风控或网络失败：`字幕获取失败，请稍后刷新`。
- 播放器未就绪：字幕照常显示，跳转时提示 `播放器尚未加载，请稍后重试`。

所有失败状态保留返回和刷新入口。错误不得触发第三方 API、AI 模型、音频下载或本地 ASR。请求中切换标签页、视频或分 P 时静默丢弃过期结果，并为新身份重新进入加载状态。

## 参考项目与许可

字幕获取、WBI 签名、轨道优先级和中文分段可参考 `biuworks/bilibili-digest`，但应按 Clip2MD 的 TypeScript、消息守卫和平台适配器边界重新实现，避免整体复制其 background 或 sidepanel 单体代码。

参考仓库使用 MIT 许可证。若实现中复制了具有实质性的源代码或算法表达，必须在仓库分发材料中保留对应版权和许可说明；仅参考行为并独立实现时，仍应在相关文档中注明灵感来源。

## 测试与验收

自动化测试至少覆盖：

- WBI 签名固定向量和参数排序。
- 人工/AI、中文/其他语言的字幕轨优先级与手动切换。
- 中文字幕自然断句、时长/长度上限以及不丢字、不重字。
- 会话缓存命中、刷新绕过缓存、视频或分 P 身份隔离。
- 原侧栏字幕按钮仅在 B 站视频页显示，且不依赖一图速览结果。
- 两个 HTML 页面双向导航，构建产物包含字幕页三项资源。
- 字幕文本安全渲染，不执行 HTML 或事件属性。
- 播放状态读取、身份校验、时间跳转和暂停状态保持。
- 当前字幕高亮、自动跟随、手动滚动暂停和“回到当前句”。
- 登录限制、无字幕、空字幕、网络失败、播放器未加载和过期请求。

完成实现后运行完整测试、TypeScript 类型检查和生产构建。真实 B 站验收至少覆盖一个人工字幕视频、一个 AI 字幕视频、一个多字幕轨视频、一个无字幕视频和一个多分 P 视频；重新加载扩展后验证入口、页面往返、轨道恢复、刷新、播放跟随和跳转。其他已支持平台的一图速览必须保持原有行为。
